# Practice Lab — Administrator Guide

## What is Practice Lab?

Practice Lab helps your team rehearse difficult workplace conversations with AI characters. After each practice session, employees receive structured coaching feedback based on a scoring rubric.

## Getting Started

1. Sign in as an administrator
2. Go to **Manage Scenarios** in the navigation
3. Review the four pre-built scenarios or create new ones
4. Assign scenarios to employees (via assignments)

## Creating a Scenario

### Basic Information
- **Title** — What employees see in the scenario library
- **Description** — Brief overview of the practice situation
- **Category** — Parent conversations, instructor coaching, supervisor feedback, or coworker communication
- **Difficulty** — Beginner, intermediate, or advanced
- **Employee Role** — What role the employee plays (e.g., "Front desk staff")
- **Passing Score** — Minimum percentage to pass (default: 70%)

### AI Character
- **Character Name and Role** — Who the employee talks to
- **Character Description** — Personality and background
- **Opening Message** — How the character starts the conversation

### Scenario Logic
- **Situation Background** — Context the character knows
- **Hidden Information** — Details revealed only when appropriate (employees never see this)
- **Escalation Triggers** — What makes the character more frustrated
- **Deescalation Conditions** — What helps the character calm down
- **Success Conditions** — When the conversation can naturally conclude

### Evaluation
- **Rubric Criteria** — Skills being evaluated (weights must total 100%)
- **Critical Errors** — Serious mistakes that may cause automatic failure

## Publishing

1. Save as **Draft** while building
2. Click **Publish** when ready for employees
3. Use **Duplicate** to create variations of existing scenarios
4. **Archive** scenarios that are no longer needed
5. Use **Test Scenario** to preview a conversation without creating an employee training record

## Assigning Scenarios

Supervisors and administrators can assign scenarios from **Team Results**:

1. Choose a published scenario
2. Choose a team member
3. Optionally set a due date and mark it required
4. Employees will see the assignment in Practice Lab

## Settings

Administrators can open **Settings** to:

- Enable or disable Practice Lab
- Enable or disable voice mode
- Allow or block supervisor transcript access
- Configure transcript retention days

## Reviewing Results

- Supervisors can view team completion status and scores
- Administrators can see all attempt data
- Transcript access for supervisors is controlled in app settings

## Tips for Good Scenarios

- Write realistic opening messages
- Include specific escalation and deescalation triggers
- Keep hidden information genuinely hidden until earned through good questions
- Use the default rubric as a starting point
- Test scenarios yourself using the preview feature before assigning

## Voice Mode

Voice mode allows employees to practice speaking naturally. It requires:
- A supported browser (Chrome recommended)
- Microphone permission
- Voice mode enabled in settings

Employees can always fall back to text mode.
